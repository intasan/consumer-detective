# Consumer Detective

## Purpose

A consumer-awareness project focused on helping people identify misleading product information, suspicious pages and common online shopping risks.

## Main flow

```text
Product / Page -> Check Source -> Check Claims -> Check Seller -> Compare Evidence -> Decide Carefully
```

## Deliverables

- Research content
- Product analysis
- Presentation / poster
- Visual examples
- Consumer checklist

The latest presentation asset discussed for this project is `Consumer_Detective_Poster.pptx`.
